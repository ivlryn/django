
# Skincare E-commerce

A Django-based skincare e-commerce platform featuring user authentication, product browsing with filters, cart and checkout, and an admin interface for product management that syncs with the frontend user site.
## Features

- Login
- Register
- Product Listing( can be filter by price, category, brand)
- add to cart
- checkout
- My profile (View and update personal information and order history)
- has system admin and admin can add product and will sync to frontend end-user website


## TechStack

- **Backend**: Django ,RestAPI
- **Frontend**: JavaScript, JQuery,jazzmin(admin UI)
